1. HOW TO RUN
-------------------------------------------------------------------------------
Keep all of these files together in the same folder:

    210011253_teardrop_project.py     <- the main program
    COMPUTE_IJ_SPM.py                 <- supplied helper (source integrals)
    COMPUTE_KL_VPM.py                 <- supplied helper (vortex integrals)
    STREAMLINE_SPM.py                 <- supplied helper (source field)
    STREAMLINE_VPM.py                 <- supplied helper (vortex field)
    xfoil.exe                         <- used for the Cp comparison
    RUN_PROJECT.bat                   <- convenience launcher

Easiest way:      double-click  RUN_PROJECT.bat
Or from a terminal opened in this folder:

    python 210011253_teardrop_project.py

Only numpy and matplotlib are required. The .bat file installs them if
they are missing. The whole run takes roughly 30 seconds.


2. WHAT THE PROGRAM DOES
-------------------------------------------------------------------------------
STEP 1  Settings              - freestream, panel counts, grid size
STEP 2  Geometry              - the teardrop shape and its panels
STEP 3  SOURCE panel method   - solved on the COMPLETE body
STEP 4  VORTEX panel method   - solved on the UPPER HALF only (symmetry)
STEP 5  Flow field            - streamlines and velocity field on a grid
STEP 6  Pressure field        - Cp field, equivalently p - p_inf
STEP 7  XFOIL                 - same geometry run in XFOIL for comparison
STEP 8  Cp vector plots       - for both methods
STEP 9  Summary               - all numbers printed and saved to a text file

This satisfies the assignment requirement of applying the VORTEX panel method
to one half of the geometry and the SOURCE panel method to the complete body.

4. HOW THE RESULTS WERE CHECKED
-------------------------------------------------------------------------------
* Stagnation pressure        Cp maximum comes out as 0.9935, against the exact
                             theoretical value of 1.0.

* Closed-body source balance sum(lambda_j * S_j) = 6.6e-03, i.e. essentially
                             zero, as it must be for a closed body.

* Boundary conditions        The no-penetration residual is about 1e-15 for
                             both methods, so the linear systems are solved
                             correctly.

* Symmetry                   CL = 0 and total circulation = 0, which is what a
                             symmetric body at zero incidence must give.

* d'Alembert paradox         CD = 0.0047, essentially zero, as inviscid theory
                             requires.

* Pressure field             The highest pressure in the field is +0.6098 Pa
                             above freestream, at the two stagnation points,
                             and the lowest is -1.3729 Pa, over the shoulder.
                             These follow the Cp field through
                             p - p_inf = 0.5*rho*V_inf^2*Cp.

* XFOIL                      Source-method Cp RMSE is 0.011 on the upper
                             surface and 0.010 on the lower surface.


5. NOTE ON THE VORTEX PANEL METHOD
-------------------------------------------------------------------------------
The source method matches XFOIL almost exactly. The vortex method is less
accurate on this shape, and that is expected rather than a coding error.

The reason is that at alpha = 0 a symmetric body carries no circulation, so
vortex panels alone are not the natural singularity for a pure thickness
problem. In addition, the teardrop has a SHARP trailing edge, where the true
vortex sheet strength is singular. A constant-strength (first-order) vortex
panel cannot represent that singularity, so the error does NOT decrease as
panels are added.

The program therefore runs a panel-count sensitivity study and prints it in
the summary instead of hiding this behaviour. Among the counts tested,
4 upper-half panels give the lowest Cp error against XFOIL, so that value is
used. Capturing the sharp trailing edge properly would require a higher-order
(linear-strength) vortex panel.

To reproduce the study yourself, change N_VPM_HALF near the top of the script
and run it again.
